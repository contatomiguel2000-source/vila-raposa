# Educandário Vila Raposa

Site em Next.js, publicado no hub com o slug `/vila-raposa` (ver `src/lib/base-path.ts`). Layout inspirado no template LITTLEA (https://littlea.framer.website/), com o amarelo e o marrom do uniforme e a raposinha mascote.

- Conteúdo: Instagram [@vila_raposa_educandario](https://www.instagram.com/vila_raposa_educandario/) e avaliações reais do Google Maps (`src/lib/data.ts`).
- Fotos otimizadas em `public/img`. Os originais ficam em `midia-original/` (fora do Git).

```bash
npm run dev   # http://localhost:3000/vila-raposa
```
